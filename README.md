# Skyblock Config Manager

Running several Hypixel SkyBlock mods often means duplicate features: two dungeon maps, three burrow guessers, double pest alerts. Skyblock Config Manager finds the settings your mods share and keeps each feature on in only the mod you choose.

## Download

Get the [latest release](../../releases/latest):

- **Windows:** `SkyblockConfigManager.exe`, or the `.zip` if your browser blocks it. If "Windows protected your PC" shows up, click **More info**, then **Run anyway**.
- **macOS:** `SkyblockConfigManager-macOS.zip`. Unzip it and open the app. If macOS blocks it, click **Open Anyway** in **System Settings → Privacy & Security**.
- **Linux:** `SkyblockConfigManager-Linux.zip`. Unzip it and run `./SkyblockConfigManager`.

## How to Use It

1. Close Minecraft.
2. Open the app. It finds your `config` folder, or click **Browse…** to pick it.
3. In the **Priorities** tab, pick the mod to keep for each area.
4. Click **Resolve conflicts**, then **Save changes**. Your original files are backed up first.

The app updates itself from the **App updates** tab.
